# C Basics

This repository contains basic C programs to help beginners understand the fundamentals of C programming.

## Files Included
- demo.c – Simple demo program
- practice.c – Practice examples
- printf.c – Using printf for output
- shape.c – Programs related to shapes
- variable.c – Understanding variables in C

## How to Run
1. Make sure you have GCC installed.
2. Compile any program using:
   gcc filename.c -o output
3. Run the program:
   ./output

## Purpose
This repository is for learning and practicing basic C programming concepts.
